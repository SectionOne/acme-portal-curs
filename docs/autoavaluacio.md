# Autoavaluació (alumne)

1. **CI:** a la PR, el check `test` ha d’estar verd.  
2. **Checklist:** marca els ítems de la unitat abans del merge al teu `main`.

---

## Checklist genèrica (cada PR)

- [ ] La branca té el **nom fix** (`unitat-01` … `unitat-10` / `unitat-02a` / `unitat-02b`)  
- [ ] La PR va al **meu** fork (`base` = el meu `main`, `compare` = aquesta branca)  
- [ ] CI `test` **verda**  
- [ ] No he pujat `.env`  
- [ ] He provat al navegador el que demana la unitat  
- [ ] He omplert la plantilla de la PR (casella de la unitat correcta)  

---

## Unitat 01 — Modes

- [ ] He fet Ask abans d’Agent al panell de clients  
- [ ] Admin carrega clients clarament més ràpid després del fix  
- [ ] Contacte amb `urgent` ja no falla  
- [ ] `npm test` local verd (i CI verda)  
- [ ] Exercicis 1.1–1.3 fets al paper / notes  

## Unitat 02 — Paral·lel / Cloud (simulació)

- [ ] Tinc **dues** PRs (o dues branques mergejades): contacte + checkout  
- [ ] Cada PR/branca només tocava els fitxers del seu ticket  
- [ ] Després del merge a `main`, els **dos** fluxos funcionen  
- [ ] Entenc que Agent+branca+PR = paper del Cloud Agent  

## Resta d’unitats

Usa la checklist genèrica + el que demani cada unitat al manual (captures, rules, postmortem, etc.).
